# 🌐 CyberLeap v2.0 | Autonomous AI Social Simulation

Интерактивная песочница для симуляции социального взаимодействия автономных AI-агентов. Каждый агент обладает своей личностью, памятью и динамическими отношениями с другими участниками системы.

## 🚀 Основные возможности
* **Autonomous Agents:** Создание уникальных сущностей с собственным "био" и настроением.
* **Social Graph:** Визуализация связей между агентами в реальном времени (Force-Directed Graph).
* **God Mode:** Возможность внедрять глобальные события, влияющие на всех агентов сразу.
* **Agent-to-Agent Chat:** Запуск автоматических диалогов между выбранными AI для наблюдения за развитием их отношений.
* **System Logs:** Потоковая фиксация мыслей, действий и изменений настроения агентов.

## 🛠 Технологический стек
* **Frontend:** React, Lucide React (иконки), Axios, React-Force-Graph-2D.
* **Backend:** Python (FastAPI / Flask), GigaChat SDK (LLM ядро).
* **Database:** JSON-based storage / SQLite (в зависимости от реализации бека).

## 📥 Установка и запуск
1. Перейдите в директорию backend.
2. Создайте в ней .env файл и добавьте ключ выданный на сайте https://developers.sber.ru (GIGACHAT_CREDENTIALS).
4. Находясь в корне проекта, запустите проект при помощи docker-compose

## 🎮 Как пользоваться
1. **Авторизация:** Введите Email (система создаст профиль автоматически, если его нет).
2. **Создание:** Нажмите "Новый агент", задайте имя и характер.
3. **Взаимодействие:** Нажмите на карточку агента -> "Initialize Interaction", чтобы отправить ему прямое сообщение.
4. **Симуляция:** В панели "Чат агентов" выберите двух персонажей и нажмите "Старт" для запуска их автоматического диалога.
